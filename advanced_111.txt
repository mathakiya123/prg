<?php
class BankAccount {
    private $balance;

   
    public function __construct($amount) {
        $this->balance = $amount;
    }

    
    public function deposit($amount) {
        $this->balance += $amount;
    }

    public function withdraw($amount) {
        if ($amount <= $this->balance) {
            $this->balance -= $amount;
        } else {
            echo "Insufficient balance!<br>";
        }
    }


    public function getBalance() {
        return $this->balance;
    }
}


$account = new BankAccount(1000);
$account->deposit(500);
$account->withdraw(200);

echo "Current Balance: " . $account->getBalance();  
?>

1)Explain the concept of abstraction and the use of interfaces in PHP
=>
What is Abstraction?

Abstraction is one of the main pillars of Object-Oriented Programming (OOP).
It means hiding the complex implementation details and showing only the essential features of an object.

In simple terms:
You only show what an object does, not how it does it.

=> Purpose of Abstraction:

To simplify complex systems by breaking them into smaller, understandable parts.

To focus on essential operations rather than internal logic.

To achieve loose coupling between components (less dependency).

To enforce a common structure for multiple classes.

=> How Abstraction is Implemented in PHP:

In PHP, abstraction can be achieved in two ways:

Using Abstract Classes

Using Interfaces

Definition:

Magic methods in PHP are special built-in methods that begin with a double underscore (__).
They are automatically triggered by certain actions in a class — for example, when creating an object, accessing an undefined property, or calling a non-existent method.

=> In simple terms:
Magic methods allow you to customize how objects behave in specific situations.

purpose of Magic Methods:

To control or override default behavior of PHP classes and objects.

To handle dynamic operations such as reading/writing inaccessible properties.

To initialize or clean up objects automatically (using __construct() and __destruct()).

=>
Definition:

In PHP, the final keyword is used to restrict inheritance or method overriding.
It can be applied to both classes and methods.

Purpose:

The main purpose of the final keyword is to protect code from being modified in subclasses.
It ensures that:

A final class cannot be inherited.

A final method cannot be overridden in a child class.
